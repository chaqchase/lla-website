`youtube` opens a YouTube search in your browser from a terminal prompt with live suggestions. Reach for it when you're working in the terminal and want to find a video.

## Actions

Run an action with `lla plugin run youtube <action>`.

| Action | What it does |
| --- | --- |
| `search` | Prompt for a query with live suggestions, then open the results |
| `search-selected` | Same prompt, filled in from your clipboard |
| `history` | Search again, copy, delete or clear past searches, or see statistics |
| `preferences` | Change settings |
| `help` | Show help |

All of them are interactive, so they need a TTY. Despite its name, `search-selected` can't see selected text, so copy the text first.

## Example

```bash
lla plugin run youtube search
```

Type a query, pick a suggestion with the arrow keys if you want one, and press Enter. This opens `https://www.youtube.com/results?search_query=<query>` in your default browser.

## Settings

Edit `~/.config/lla/plugins/youtube/config.toml`, or run the `preferences` action.

| Key | Default | What it does |
| --- | --- | --- |
| `remember_search_history` | `true` | Save searches in `search_history`, in the same file |
| `use_clipboard_fallback` | `true` | Let `search-selected` read the clipboard. When `false`, it fails with `No text available in clipboard. Copy some text first.` |
| `max_history_size` | `100` | Searches to keep |

## Permissions

The plugin can reach `youtube.com` and `suggestqueries.google.com`, and use the clipboard and open URLs. What you type goes to `suggestqueries.google.com` over plain HTTP before you press Enter, so don't type anything private into the prompt. Suggestions are cached for an hour.
