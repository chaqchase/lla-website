`reclaimable_space` marks caches, build output and temporary files in the [size map view](/docs/usage/views#size-map-view) and shows how many bytes each one holds. Reach for it when a disk is filling up and you want to know what's safe to clear. It never deletes anything.

## Turn it on

```toml
# ~/.config/lla/config.toml
enabled_plugins = ["reclaimable_space"]
```

Or run `lla --enable-plugin reclaimable_space`, which writes the same setting, so it stays on. `lla --disable-plugin reclaimable_space` removes it.

The plugin only runs in the size map view (`-S`). Add `--include-dirs` so directories show their real size.

Matching entries get three typed fields: `reclaimable_bytes` (bytes), `reclaim_reason` (string) and `reclaim_confidence` (string). Read them from JSON, and keep `-S` in the command, since `lla --json` alone leaves them out:

```bash
lla -S --include-dirs --json | jq -c '.[] | select(.plugin.reclaimable_bytes) | {name, bytes: .plugin.reclaimable_bytes, confidence: .plugin.reclaim_confidence}'
```

```text
{"name":"dist","bytes":100000,"confidence":"medium"}
{"name":"node_modules","bytes":40000,"confidence":"high"}
{"name":"target","bytes":3000000,"confidence":"high"}
```

`field:` columns stay empty, because the long and table views don't run this plugin.

## What it matches

Matching uses the name alone and ignores case, so a directory you wrote by hand called `build` is marked too. Check `medium` entries before you delete them.

| Name | Reason | Confidence |
| --- | --- | --- |
| `node_modules` | dependency cache | high |
| `target`, `__pycache__`, `.pytest_cache`, `.mypy_cache`, `.ruff_cache`, `.cache`, `.parcel-cache`, `.turbo` | generated cache | high |
| `.next`, `coverage`, `dist`, `build` | build output | medium |
| `.DS_Store`, `Thumbs.db` | system metadata | high |
| Names ending in `~`; `.tmp`, `.temp`, `.swp`, `.swo`, `.bak`, `.old` | temporary file | high |
| `.pyc`, `.class`, `.o`, `.obj` | generated artifact | high |
| `.log` | log file | medium |

The first three rows match directories, and the rest match files.

## Actions

Run an action with `lla plugin run reclaimable_space <action>`.

| Action | What it does |
| --- | --- |
| `inspect -- <path>` | Explain whether a path is safely reclaimable |

`inspect` isn't interactive, so it works in scripts and prints JSON without a TTY.

```bash
lla plugin run reclaimable_space inspect -- target
```

```text

  "confidence": "high",
  "path": "target",
  "reason": "generated cache",
  "reclaimable": true,
  "reclaimable_bytes": 3000000
}
```
