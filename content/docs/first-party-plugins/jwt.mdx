`jwt` decodes a JSON Web Token and prints its header, payload and signature. Reach for it when you're debugging auth and want to read a token's claims without pasting it into a website. It has no network access. It also doesn't verify signatures, so a decoded token isn't a trusted one.

## Actions

Run an action with `lla plugin run jwt <action>`.

| Action | What it does |
| --- | --- |
| `decode` | Decode a token you paste, take from the clipboard or pick from history |
| `search` | Search decoded tokens with a regex over header and payload keys and values |
| `history` | Copy or remove saved tokens, or clear the list |
| `preferences` | Change settings |
| `help` | Show help |

All of them are interactive, so they need a TTY. None takes arguments, since tokens come in through a prompt.

## Example

```bash
lla plugin run jwt decode
```

Choose Paste JWT token and paste it:

```text
┌─ HEADER ─────────────────────────────────────────────────────────────┐
{
  alg: "HS256",
  typ: "JWT"
}
└──────────────────────────────────────────────────────────────────────┘

┌─ PAYLOAD ────────────────────────────────────────────────────────────┐
{
  aud: "api",
  exp: 1700003600,
  iat: 1700000000,
  iss: "https://auth.example.com",
  role: "admin",
  sub: "user-42"
}
└──────────────────────────────────────────────────────────────────────┘

┌─ SIGNATURE ──────────────────────────────────────────────────────────┐
  c2lnbmF0dXJl
└──────────────────────────────────────────────────────────────────────┘
```

If the token has an `exp` claim, a line such as `Expired 1085 days ago` reports its status. A menu then lets you copy the header, the payload, the full token or one claim, or save the token to history.

<Callout type="warning" title="History stores raw tokens">
Save to history writes the whole token in plain text to the config file. Don't save tokens that are still valid, or set `save_to_history = false`.
</Callout>

## Settings

Edit `~/.config/lla/plugins/jwt/config.toml`, or run the `preferences` action.

| Key | Default | What it does |
| --- | --- | --- |
| `max_history_size` | `50` | Tokens to keep in history |
| `auto_check_expiration` | `true` | Report expiry when a token has an `exp` claim |
| `save_to_history` | `true` | Allow Save to history |
| `highlight_claims` | `["sub", "iss", "aud", "exp", "iat", "nbf"]` | Claims to highlight in the payload |
