`kill_process` lists running processes and terminates the ones you choose. Reach for it when you want to find a process by name instead of looking up its PID. Every kill asks you to confirm, and the answer defaults to No.

## Actions

Run an action with `lla plugin run kill_process <action>`.

| Action | What it does |
| --- | --- |
| `list` | List running processes with name, PID, CPU usage and memory |
| `kill` | Pick processes from a searchable list and terminate them |
| `force-kill` | Same picker, but force-terminate (`SIGKILL` on Unix, `/F` on Windows) |
| `kill-by-name -- <name>` | Terminate processes whose name contains `name`, ignoring case |
| `force-kill-by-name -- <name>` | Same match, force-terminate |
| `kill-by-pid -- <pid>` | Terminate one process by PID |
| `force-kill-by-pid -- <pid>` | Force-terminate one process by PID |
| `help` | Show help |

All of them are interactive, so they need a TTY.

In the picker, type to filter and press Enter. All the filtered results move to a multi-select, where you choose which to terminate. Esc cancels.

## Example

```bash
lla plugin run kill_process kill-by-name -- chrome
```

This finds every process with `chrome` in its name and asks before terminating them. The match is a substring, so check the list it shows you before you confirm.

If a kill fails, the process may belong to another user. Run lla with `sudo`, or as Administrator on Windows.

## Permissions

`process = true`. On Unix the plugin runs `kill -15`, or `kill -9` to force. On Windows it runs `taskkill /PID`, adding `/F` to force.
