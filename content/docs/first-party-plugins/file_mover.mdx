`file_mover` collects files and directories on a clipboard, then moves them to a target directory. Reach for it when you're gathering items from several places into one. It adds nothing to listings.

The clipboard is a JSON file, separate from your system clipboard: `mv_clipboard.json` in `~/Library/Application Support/lla/` on macOS and `~/.config/lla/` on Linux.

## Actions

Run an action with `lla plugin run file_mover <action> -- <args>`. Every action is interactive, so it needs a TTY and the default `--output human`.

| Action | Arguments | What it does |
| --- | --- | --- |
| `add` | `[dir]` | Opens a multi-select for one directory and adds your picks to the clipboard. Space selects, `a` toggles all, Enter confirms. |
| `move-all` | `[target]` | Moves every clipboard item to the target and empties the clipboard. |
| `move-partial` | `[target]` | Lets you pick which clipboard items to move, and removes those from the clipboard. |
| `show` | | Shows the clipboard in a selector, where you can remove items. |
| `clear` | | Empties the clipboard. |
| `help` | | Prints usage. |

`dir` and `target` default to the current directory.

<Callout type="warning">
A file already at the destination is overwritten with no prompt. The source and target must also be on the same filesystem. Across filesystems the move fails with `Cross-device link (os error 18)`.
</Callout>

## Example

```bash
lla plugin run file_mover add -- ~/project/mv-src
lla plugin run file_mover move-all -- ~/project/mv-dst
```

```text
Success: Added 2 items to clipboard from ~/project/mv-src
Success: Moved all items to ~/project/mv-dst
```

## Permissions

`filesystem = ["read:tree", "write:selected-destination", "delete:selection"]`: it reads the source tree, writes to the target and removes the originals. It also declares `clipboard = true`, though its clipboard is the JSON file above.
