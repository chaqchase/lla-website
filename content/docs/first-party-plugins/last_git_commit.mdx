`last_git_commit` shows the last commit that touched each file in a listing. Turn it on when you want to see what changed recently without running `git log` on each file.

## Turn it on

```toml
# ~/.config/lla/config.toml
enabled_plugins = ["last_git_commit"]
```

Or run `lla --enable-plugin last_git_commit`, which writes the same setting, so it stays on. `lla --disable-plugin last_git_commit` removes it.

<Callout type="warning" title="Use an explicit path below the repository root">
`lla sdk`, and `lla` from inside a subdirectory of the repository, print a plain listing with no commits. Use `lla ./sdk` from the root, or an absolute path such as `lla "$PWD"`.
</Callout>

Output shows in the default, long and table views. In the table view, the long text follows each row.

The plugin adds three typed fields: `commit_hash` (string), `commit_author` (string) and `commit_time` (timestamp in Unix seconds). Read them from JSON:

```bash
lla --json ./sdk | jq -c '.[] | {name, hash: .plugin.commit_hash, time: .plugin.commit_time}'
```

```text
{"name":"Cargo.toml","hash":"a3f8778","time":1791386814}
{"name":"README.md","hash":"567a439","time":1786892075}
```

Or show them as columns:

```toml
[formatters.table]
columns = ["name", "field:commit_hash", "field:commit_author", "field:commit_time"]
```

```text
│ Cargo.toml │ a3f8778     │ Mohamed Achaq │ 1791386814  │
```

## Actions

The only action is `help`: `lla plugin run last_git_commit help`. It's interactive, so it needs a TTY.

## Example

```bash
lla ./sdk
```

```text
Cargo.toml
┌─
│ Commit       a3f8778 28 days ago
└─

README.md
┌─
│ Commit       567a439 80 days ago
└─
```

The long view adds the author:

```bash
lla -l ./sdk
```

```text
-rw-r--r-- 614B Oct 07 15:26 you staff Cargo.toml
┌─
│ Commit       a3f8778
│ Author       Mohamed Achaq
│ Time         28 days ago
└─
```

## Settings

Set the colors in `~/.config/lla/plugins/last_git_commit/config.toml`:

```toml
[colors]
hash = "bright_yellow"
author = "bright_cyan"
time = "bright_green"
info = "bright_blue"
```

`info` colors the labels.

## Permissions

`process = true`, because the plugin runs `git log`. It caches results until `HEAD` moves.
