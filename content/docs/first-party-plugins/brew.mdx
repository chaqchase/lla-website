`brew` runs Homebrew through `lla plugin run`: list, search, install, upgrade and remove packages, or pick from a menu. Reach for it when you want the menu or the combined formula and cask search. It adds nothing to listings and needs Homebrew installed.

## Actions

Run an action with `lla plugin run brew <action> -- <args>`. Every action is interactive, so it needs a TTY and the default `--output human`.

| Action | Arguments | What it does |
| --- | --- | --- |
| `list` | | Lists installed packages. |
| `search` | `[query]` | Searches formulae and casks, and prompts for a query if you omit it. |
| `outdated` | | Lists outdated packages. |
| `install` | `<package> [--cask]` | Installs a package. |
| `uninstall` | `<package> [--cask]` | Uninstalls a package. |
| `remove` | `<package> [--cask]` | Alias for `uninstall`. |
| `upgrade` | `[package]` | Runs `brew update`, then upgrades one package, or all of them if you name none. |
| `info` | `<package>` | Shows package details. |
| `cleanup` | | Runs `brew cleanup --prune=all`. |
| `doctor` | | Runs `brew doctor`. |
| `menu` | | Opens an interactive menu. |
| `help` | | Prints usage. |

```bash
lla plugin run brew search -- ripgrep
lla plugin run brew install -- firefox --cask
```

<Callout type="warning">
`install`, `uninstall`, `upgrade` and `cleanup` change your system right away. None of them asks for confirmation.
</Callout>

## Settings

The plugin reads `~/.config/lla/plugins/brew/config.toml`.

```toml
custom_brew_path = "/opt/homebrew/bin/brew"
greedy_upgrades = true
show_caveats = true
```

| Key | Default | Effect |
| --- | --- | --- |
| `custom_brew_path` | unset | Path to the `brew` binary. Unset, the plugin asks `brew --prefix`, then tries `/opt/homebrew` on ARM or `/usr/local`. |
| `greedy_upgrades` | `true` | `upgrade` with no package runs `brew upgrade --greedy`. |
| `show_caveats` | `true` | `info` prints package caveats. |

A `[colors]` table sets `success`, `info`, `warning`, `error`, `formula`, `cask`, `version` and `outdated`.

## Permissions

`process = true`, because it runs `brew`. `network = ["formulae.brew.sh", "github.com"]`: `search` downloads the formula and cask catalogs from `formulae.brew.sh` and caches them for one hour.
