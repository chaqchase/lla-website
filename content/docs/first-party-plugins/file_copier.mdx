`file_copier` collects files and directories on a clipboard, then copies them to a target directory. Reach for it when you're gathering items from several places into one. It adds nothing to listings.

The clipboard is a JSON file, separate from your system clipboard: `cp_clipboard.json` in `~/Library/Application Support/lla/` on macOS and `~/.config/lla/` on Linux.

## Actions

Run an action with `lla plugin run file_copier <action> -- <args>`. Every action is interactive, so it needs a TTY and the default `--output human`.

| Action | Arguments | What it does |
| --- | --- | --- |
| `add` | `[dir]` | Opens a multi-select for one directory and adds your picks to the clipboard. Space selects, `a` toggles all, Enter confirms. |
| `copy-all` | `[target]` | Copies every clipboard item to the target. Directories copy recursively, and the clipboard keeps its items. |
| `copy-partial` | `[target]` | Lets you pick which clipboard items to copy. |
| `show` | | Shows the clipboard in a selector, where you can remove items. |
| `clear` | | Empties the clipboard. |
| `help` | | Prints usage. |

`dir` and `target` default to the current directory.

<Callout type="warning">
A file already at the destination is overwritten with no prompt.
</Callout>

## Example

```bash
lla plugin run file_copier add -- ~/project/src
lla plugin run file_copier copy-all -- ~/project/dst
lla plugin run file_copier clear
```

```text
Success: Added 3 items to clipboard from ~/project/src
Success: Copied all items to ~/project/dst
Success: Clipboard cleared
```

## Permissions

`filesystem = ["read:tree", "write:selected-destination"]`: it reads the source tree and writes to the target. It also declares `clipboard = true`, though its clipboard is the JSON file above.
