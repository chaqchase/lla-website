`remove_paywall` turns a URL into an archive or reader link, copies it and opens it in your browser. Reach for it when an article won't load and you have its URL at hand.

## Actions

Run an action with `lla plugin run remove_paywall <action>`.

| Action | What it does |
| --- | --- |
| `remove [-- <url>]` | Build a link with your default service |
| `clipboard` | Build a link from the URL in your clipboard |
| `choose [-- <url>]` | Pick a service, then build the link |
| `try-all [-- <url>]` | Print links for every service and open none |
| `12ft [-- <url>]` | Use 12ft.io |
| `archive [-- <url>]` | Use archive.is |
| `freedium [-- <url>]` | Use Freedium |
| `services` | List services. `list` is an alias |
| `set-default` | Choose your default service |
| `history` | Show your latest 20 URLs and the service used for each |
| `clear-history` | Clear the history |
| `preferences` | Change settings. `config` is an alias |
| `menu` | Open the menu |
| `help` | Show help |

All of them are interactive, so they need a TTY. Leave out the URL and the plugin reads your clipboard. A URL with no scheme gets `https://`.

| Service | Link it builds |
| --- | --- |
| `TwelveFt` | `https://12ft.io/<url>` |
| `ArchiveIs` | `https://archive.is/?run=1&url=<encoded url>` |
| `RemovePaywall` | `https://www.removepaywall.com/<url>` |
| `Freedium` | `https://freedium.cfd/<url>`, for Medium articles only |
| `GoogleCache` | `https://webcache.googleusercontent.com/search?q=cache:<url>` |

## Example

```bash
lla plugin run remove_paywall archive -- https://example.com/article
```

This builds the archive.is link, copies it and opens it in your default browser.

## Settings

Edit `~/.config/lla/plugins/remove_paywall/config.toml`, or run the `preferences` action.

| Key | Default | What it does |
| --- | --- | --- |
| `default_service` | `"TwelveFt"` | Service for `remove` and `clipboard`, from the table above |
| `auto_open_browser` | `true` | Open the link after building it |
| `copy_to_clipboard` | `true` | Copy the link after building it |
| `remember_history` | `true` | Save URLs in `usage_history`, in the same file |
| `max_history_size` | `50` | Entries to keep |

## Permissions

The manifest lists `archive.is`, `12ft.io`, `removepaywall.com`, `freedium.cfd` and `webcache.googleusercontent.com` under `network`, plus `clipboard` and `open_url`. The plugin sends no HTTP requests itself. Your browser opens the link, so the service you pick sees the URL.
