`npm` looks up a package on the npm registry and shows its details and bundle size. Reach for it when you're deciding whether to add a dependency. It never runs a package manager, so nothing gets installed.

## Actions

Run an action with `lla plugin run npm <action>`.

| Action | What it does |
| --- | --- |
| `search` | Look up a package by its exact name |
| `favorites` | View details for saved packages, copy their install commands or remove them |
| `preferences` | Choose your package manager: `npm`, `yarn`, `pnpm` or `bun` |
| `help` | Show help |

All of them are interactive, so they need a TTY.

## Example

```bash
lla plugin run npm search
```

Type a package name such as `react`. `search` matches exact names only, and anything else reports `Package not found`. It shows the package's version, description, author, license, homepage, repository, and minified and gzipped size from Bundlephobia. A menu then lets you copy the install command, add the package to favorites or open its npm page.

## Settings

Edit `~/.config/lla/plugins/npm/config.toml`, or run the `preferences` action.

```toml
registry = "https://registry.npmjs.org"
package_manager = "npm"
favorites = []
```

## Permissions

The plugin can reach `registry.npmjs.org` and `bundlephobia.com`, and use the clipboard and open URLs. It caches package details for 6 hours and bundle sizes for 24 hours.
