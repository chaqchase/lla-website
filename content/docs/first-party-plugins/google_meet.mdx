`google_meet` creates a Google Meet link from your terminal, copies it and keeps a history of the links you've made. Reach for it when you need a meeting link to paste into a chat.

<Callout type="warning" title="Capturing the link needs macOS">
On Linux and Windows, `create` opens the Meet page and then fails with `Browser detection is only supported on macOS`, so you copy the link from the browser yourself.
</Callout>

## Actions

Run an action with `lla plugin run google_meet <action>`.

| Action | What it does |
| --- | --- |
| `create` | Open a new meeting in your browser, read its link, copy it and save it to history |
| `create-with-profile` | Pick a saved Google account first. With none saved, it uses your default account |
| `history` | Copy or open past links, or clear the list |
| `profiles` | Add, list or remove Google accounts |
| `preferences` | Change settings |
| `help` | Show help |

All of them are interactive, so they need a TTY.

## Example

```bash
lla plugin run google_meet create
```

This opens `https://meet.google.com/new` in your default browser. On macOS, it then reads the URL of the browser in front for up to 10 seconds, prints the link and copies it. It recognizes Google Chrome, Safari, Brave Browser, Arc, Firefox, Microsoft Edge, Chromium and Opera.

## Settings

Edit `~/.config/lla/plugins/google_meet/config.toml`, or run the `preferences` and `profiles` actions.

```toml
auto_copy_link = true
max_history_size = 50

[[browser_profiles]]
name = "Work"
profile_path = "you@example.com"
```

`profile_path` is an email address or account number, and it's sent as `?authuser=` in the Meet URL. Past links are stored in the same file under `meet_history`.

## Permissions

The manifest lists `meet.google.com` under `network`, plus `clipboard` and `open_url`. The plugin sends no HTTP requests itself. It runs `open`, `xdg-open` or `cmd /C start` to open your browser, and `osascript` to read its URL.
