`file_meta` prints the access, modified and created times, UID and GID, size and mode under each file and directory. Turn it on when you need exact timestamps or numeric owners that a normal listing hides.

<Shot name="plugin-file-meta" alt="A long listing in which each entry also shows its accessed, modified and created times, UID and GID, size and permissions." caption="`lla -l --hide-group <dir>` with only `file_meta` enabled." />

## Turn it on

```toml
# ~/.config/lla/config.toml
enabled_plugins = ["file_meta"]
```

Or run this once. It saves the same setting, so the plugin stays on until you run `lla --disable-plugin file_meta`.

```bash
lla --enable-plugin file_meta
```

The same block appears in the default and long views (`formats = ["default", "long"]`), and in the table view, which uses the long format.

| Field | Type | Holds |
| --- | --- | --- |
| `size` | bytes | Size in bytes |
| `modified` | timestamp | Modified time as epoch seconds |
| `permissions` | integer | Mode as a decimal number, such as `33188` for `100644` |

JSON also carries untyped strings: `accessed`, `created`, `uid` and `gid`.

```bash
lla --json | jq '.[] | select(.name=="README.md") | .plugin'
```

```text
{
  "modified": 1793832837,
  "permissions": 33188,
  "accessed": "1793832837",
  "uid": "501",
  "gid": "20",
  "created": "1793832837",
  "size": 7
}
```

You can also add them as [columns](/docs/usage/views#choose-the-columns), such as `field:modified`. These print the same raw values.

## Actions

Run an action with `lla plugin run file_meta help`. `help` prints usage and is interactive, so it needs a TTY and the default `--output human`. Running it also enables the plugin and saves that setting.

## Example

The `Permissions` row includes the file type bits: `100644` is a regular file and `40755` is a directory.

```bash
lla -l --hide-group
```

```text
-rw-r--r--  17B Aug 13 05:21 you .gitignore 
┌─
│ Accessed     2024-08-13 05:21:04
│ Modified     2024-08-13 05:21:04
│ Created      2024-08-13 05:21:04
│ UID/GID      501/20
│ Size         17 B
│ Permissions  100644
└─
```

## Settings

`~/.config/lla/plugins/file_meta/config.toml` sets colors in a `[colors]` table: `accessed`, `modified`, `created`, `ownership`, `size` and `permissions`.
