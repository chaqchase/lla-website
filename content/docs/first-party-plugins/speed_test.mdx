`speed_test` measures your network latency and download speed from the terminal and keeps a history of results. Reach for it when a connection feels slow and you want a number. It doesn't test upload speed.

## Actions

Run an action with `lla plugin run speed_test <action>`.

| Action | What it does |
| --- | --- |
| `test` | Measure latency to Cloudflare, Google and OpenDNS, download from Cloudflare, Hetzner and OVH, then print the best results and a rating |
| `quick` | Download from Cloudflare only, and print download speed and latency |
| `history` | Show the latest 20 results |
| `clear-history` | Clear the history |
| `menu` | Open the menu, including Settings |
| `help` | Show help |

All of them are interactive, so they need a TTY.

## Example

```bash
lla plugin run speed_test quick
```

This downloads 10 MB from Cloudflare by default and prints the result. A full `test` downloads about 30 MB, which matters on a metered connection.

## Settings

Change these under `menu`, then Settings. They're stored in `~/.config/lla/plugins/speed_test/config.toml`, along with past results.

| Key | Default | What it does |
| --- | --- | --- |
| `test_size_mb` | `10` | Download size. Cloudflare uses it as given, from 1 to 100. Hetzner and OVH round to a 1, 10 or 100 MB file |
| `remember_history` | `true` | Save results in `test_history`, in the same file |
| `max_history_size` | `50` | Results to keep |

## Permissions

The plugin can reach `speed.cloudflare.com`, `nbg1-speed.hetzner.com`, `proof.ovh.net`, `cloudflare-dns.com`, `dns.google` and `welcome.opendns.com`.
