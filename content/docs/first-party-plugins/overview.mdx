These 37 plugins are built and tested with every lla release. Install them all at once, then turn on the ones you want:

```bash
lla install --prebuilt
lla use
```

[Plugins](/docs/plugins/overview) explains installing, permissions and running actions.

## Project and code

| Plugin | What it does |
| --- | --- |
| [`activity_history`](/docs/first-party-plugins/activity_history) | Adds Git-backed file activity to timeline listings |
| [`change_risk`](/docs/first-party-plugins/change_risk) | Adds a risk level and score to the Git view |
| [`code_complexity`](/docs/first-party-plugins/code_complexity) | Analyzes source-code complexity |
| [`code_snippet_extractor`](/docs/first-party-plugins/code_snippet_extractor) | Extracts and manages tagged code snippets |
| [`git_status`](/docs/first-party-plugins/git_status) | Exposes repository and per-entry Git status |
| [`keyword_search`](/docs/first-party-plugins/keyword_search) | Searches selected files for keywords |
| [`last_git_commit`](/docs/first-party-plugins/last_git_commit) | Exposes the last commit for each entry |
| [`project_context`](/docs/first-party-plugins/project_context) | Detects project type, toolchains, locks, artifacts and repository health |
