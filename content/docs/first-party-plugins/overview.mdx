# Bundled plugin catalog

These plugins are built and verified as part of every lla release.

- [`activity_history`](/docs/first-party-plugins/activity_history) — Add Git-backed file activity history to timeline listings (`dev.lla.activity-history`)
- [`brew`](/docs/first-party-plugins/brew) — Manage Homebrew packages (`dev.lla.brew`)
- [`categorizer`](/docs/first-party-plugins/categorizer) — Categorize files from extensions and metadata (`dev.lla.categorizer`)
- [`change_risk`](/docs/first-party-plugins/change_risk) — Estimate per-file change risk from size, complexity, Git churn, and worktree state (`dev.lla.change-risk`)
- [`code_complexity`](/docs/first-party-plugins/code_complexity) — Analyze source-code complexity (`dev.lla.code-complexity`)
- [`code_snippet_extractor`](/docs/first-party-plugins/code_snippet_extractor) — Extract and manage tagged code snippets (`dev.lla.code-snippet-extractor`)
- [`dirs_meta`](/docs/first-party-plugins/dirs_meta) — Calculate directory counts and sizes (`dev.lla.dirs-meta`)
- [`duplicate_file_detector`](/docs/first-party-plugins/duplicate_file_detector) — Detect files with identical content (`dev.lla.duplicate-file-detector`)
- [`file_copier`](/docs/first-party-plugins/file_copier) — Interactively copy files and directories (`dev.lla.file-copier`)
- [`file_hash`](/docs/first-party-plugins/file_hash) — Calculate file hashes (`dev.lla.file-hash`)
- [`file_meta`](/docs/first-party-plugins/file_meta) — Expose detailed filesystem metadata (`dev.lla.file-meta`)
- [`file_mover`](/docs/first-party-plugins/file_mover) — Interactively move files and directories (`dev.lla.file-mover`)
- [`file_organizer`](/docs/first-party-plugins/file_organizer) — Organize files using configurable strategies (`dev.lla.file-organizer`)
- [`file_remover`](/docs/first-party-plugins/file_remover) — Interactively trash files by default with explicit permanent deletion (`dev.lla.file-remover`)
- [`file_tagger`](/docs/first-party-plugins/file_tagger) — Attach and query user-defined file tags (`dev.lla.file-tagger`)
- [`flush_dns`](/docs/first-party-plugins/flush_dns) — Flush the operating system DNS cache (`dev.lla.flush-dns`)
- [`folder_cleaner`](/docs/first-party-plugins/folder_cleaner) — Plan, quarantine and restore generated-folder cleanup (`dev.lla.folder-cleaner`)
- [`git_status`](/docs/first-party-plugins/git_status) — Expose repository and per-entry Git status (`dev.lla.git-status`)
- [`google_meet`](/docs/first-party-plugins/google_meet) — Create and manage Google Meet links (`dev.lla.google-meet`)
- [`google_search`](/docs/first-party-plugins/google_search) — Search Google with suggestions and history (`dev.lla.google-search`)
- [`hackernews`](/docs/first-party-plugins/hackernews) — Browse Hacker News stories and discussions (`dev.lla.hackernews`)
- [`jwt`](/docs/first-party-plugins/jwt) — Decode and inspect JSON Web Tokens (`dev.lla.jwt`)
- [`keyword_search`](/docs/first-party-plugins/keyword_search) — Search selected file contents for keywords (`dev.lla.keyword-search`)
- [`kill_process`](/docs/first-party-plugins/kill_process) — Inspect and terminate operating-system processes (`dev.lla.kill-process`)
- [`last_git_commit`](/docs/first-party-plugins/last_git_commit) — Expose the last Git commit for each entry (`dev.lla.last-git-commit`)
- [`media_inspector`](/docs/first-party-plugins/media_inspector) — Inspect MIME, dimensions, EXIF, duration, codecs, and bitrate (`dev.lla.media-inspector`)
- [`npm`](/docs/first-party-plugins/npm) — Search npm packages and inspect bundle size (`dev.lla.npm`)
- [`preview`](/docs/first-party-plugins/preview) — Preview source text, Markdown, images, and archives in the terminal (`dev.lla.preview`)
- [`project_context`](/docs/first-party-plugins/project_context) — Detect project type, toolchains, dependency locks, artifacts, and repository health (`dev.lla.project-context`)
- [`reclaimable_space`](/docs/first-party-plugins/reclaimable_space) — Identify generated, cached, and temporary files that can be reclaimed (`dev.lla.reclaimable-space`)
- [`remove_paywall`](/docs/first-party-plugins/remove_paywall) — Create archival and reader links for URLs (`dev.lla.remove-paywall`)
- [`security_audit`](/docs/first-party-plugins/security_audit) — Audit unsafe permissions, privileged bits, risky symlinks, and exposed secrets (`dev.lla.security-audit`)
- [`sizeviz`](/docs/first-party-plugins/sizeviz) — Visualize file sizes (`dev.lla.sizeviz`)
- [`speed_test`](/docs/first-party-plugins/speed_test) — Measure network latency and throughput (`dev.lla.speed-test`)
- [`trash`](/docs/first-party-plugins/trash) — Cross-platform recoverable deletion with restore support (`dev.lla.trash`)
- [`tree_summary`](/docs/first-party-plugins/tree_summary) — Add recursive directory totals to tree listings (`dev.lla.tree-summary`)
- [`youtube`](/docs/first-party-plugins/youtube) — Search and open YouTube videos (`dev.lla.youtube`)
