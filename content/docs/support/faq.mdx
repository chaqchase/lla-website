## Setup

### Is lla free?

Yes. lla is open source under the MIT license. `lla --license` prints the text.

### Which platforms does lla run on?

Linux, macOS, Windows and NetBSD. Static musl builds for Linux can't load plugins. See [Installation](/docs/about/installation) for each platform's builds.

### Do I have to configure lla first?

No. The first run writes `~/.config/lla/config.toml` with default values. Run `lla init` for a setup wizard, or change one value at a time with `lla config --set`.

### How do I upgrade lla?

Run `lla upgrade`. It replaces the binary at its current path with the latest release. Add `-v <version>` for a specific release tag, or `--path <path>` to install somewhere else.

### How do I uninstall lla?

Remove the binary with `sudo rm /usr/local/bin/lla` if you used the install script, or `cargo uninstall lla` if you used Cargo. Then delete lla's directories, and remove the `j` function from your shell's startup file if you ran `lla jump --setup`.

| What | Linux | macOS |
| --- | --- | --- |
| Config, themes, plugins | `~/.config/lla` | `~/.config/lla` |
| Jump bookmarks and history | `~/.config/lla/jump.json` | `~/Library/Application Support/lla` |
| WebAssembly plugin cache | `~/.cache/lla` | `~/Library/Caches/lla` |

## Listings

### Can I alias ls to lla?

Yes, with one catch: some short flags mean something else. `alias ls='lla'` works, and `alias ll='lla -l'` gives you long view.

| Flag | In `ls` | In `lla` |
| --- | --- | --- |
| `-t` | Sort by time | Tree view |
| `-S` | Sort by size | Size map view |
| `-d` | List the directory itself | Set depth, takes a value |
| `-h` | Human-readable sizes | Print help |
| `-1` | One entry per line | Not accepted |

For `ls -lt`, use `lla -l -s date -r`. Long view sizes are always human-readable.

### How do I hide dotfiles?

lla shows them by default. Run `lla --no-dotfiles` to hide them once, or `lla config --set filter.no_dotfiles true` to hide them for every run. With the setting on, `lla -a` shows them for one run.

### What's the difference between -t and -R?

`-t` draws one nested tree. `-R` prints a section for each directory. Both show dotfiles unless you pass `--no-dotfiles`, and both list `.git` without going into it.

```text
./src
────────────────────────────────────────
2026-11-04 23:01 │ lib.rs
2026-11-04 23:01 │ main.rs
```

Both also stop at `default_depth`, which starts at 3. Use `lla -t -d 6` for one run, or `lla config --set default_depth 6` to keep it.

### How do I make long view the default?

Run `lla config --set default_format long`. The accepted values are `default`, `long`, `tree`, `grid`, `git`, `timeline`, `sizemap`, `table` and `fuzzy`. A view flag still overrides this setting for one run.

### Can lla hide files listed in .gitignore?

Yes, inside or outside a Git repository. Run `lla --respect-gitignore` once, or `lla config --set filter.respect_gitignore true` to keep it. With the setting on, `lla --no-gitignore` shows those files for one run.

### Can lla list what's inside an archive?

Yes, for `.zip`, `.tar`, `.tar.gz` and `.tgz`. Views, filters and machine output all work without extracting anything. Other formats, such as `.tar.bz2`, list as a single file.

```bash
lla project.tar.gz -t
```

### How do I get JSON or CSV?

Use `--json`, `--ndjson` or `--csv`. Add `--pretty` to indent `--json`. See [Machine output](/docs/usage/machine-output) for the fields.

```bash
lla --json | jq -r '.[] | select(.file_type == "file") | "\(.size_bytes) \(.name)"'
```

## Git and search

### Does lla need Git?

Only for `lla -G` and `lla diff --git`, which run the `git` command. Every other view works without it.

### Does search need ripgrep?

Yes. `lla --search` runs `rg`, so it must be on your `PATH`.

### Is search literal or regex?

Literal and case-insensitive by default. Start the pattern with `regex:` for a regular expression, and add `-c` for exact case.

```bash
lla --search 'regex:fn\s+main' -c
```

## Plugins

### How do I install plugins?

`lla install` downloads the prebuilt bundle for your platform and needs no toolchain. Building from source needs Rust.

```bash
lla install
lla install --git https://github.com/chaqchase/lla
lla install --dir ~/code/my-plugin
```

### How do I turn a plugin on or off?

Run `lla use` for a menu, or `lla --enable-plugin file_hash` and `lla --disable-plugin file_hash`. Both flags save the change to `enabled_plugins`, so it lasts beyond the current run.

### Why does a plugin keep showing up in my listings?

It's enabled. Running an action or a [shortcut](/docs/plugins/shortcuts) on a disabled plugin turns it on and leaves it on. Run `lla --disable-plugin NAME` to stop it.

### Where are plugins stored?

In `~/.config/lla/plugins`, which you can change with `plugins_dir`. lla also searches any directories in `plugin_dirs` and a system path such as `/usr/local/lib/lla/plugins`. `lla plugin doctor` prints every path it checks.

### Are plugins sandboxed?

WebAssembly plugins are, and you approve their permissions at install time. Native plugins run with your full user rights, so only install ones you trust. `lla plugin permissions NAME` prints what a plugin declares.

### Can I write a plugin in another language?

Rust is the language the SDK supports. Other languages can generate WebAssembly Component Model bindings from `sdk/wit/lla-plugin.wit`. See [Developing plugins](/docs/plugins/developing).

## Customization

### How do I change the theme?

A new install has no other themes, so pull them, then pick one with the arrow keys. To set one without the picker, run `lla config --set theme nord`. See [Themes](/docs/usage/configuration#themes).

```bash
lla theme pull
lla theme
```

### Can I write my own theme?

Yes. A theme is a TOML file with a `name` and a `[colors]` table. Start by copying a theme from `~/.config/lla/themes`, then install and select your copy.

```bash
lla theme install my_theme.toml
lla config --set theme my_theme
```

### Can a project have its own settings?

Yes. Put a `.lla.toml` file in the project, with a line such as `default_format = "tree"`. lla applies the nearest one, looking up from the current directory, on top of your global config. `lla config show-effective` prints the merged result.

### How do I reset my config?

Delete `~/.config/lla/config.toml`. The next run writes a new one with default values. `lla init --default` won't overwrite a file that already exists.

## Moving from eza

### What are the lla equivalents of common eza flags?

| eza | lla |
| --- | --- |
| `eza -l` | `lla -l` |
| `eza -T` | `lla -t` (`lla -T` is table view) |
| `eza --git` | `lla -G` |
| `eza -s size` | `lla -s size` |
| `eza -r` | `lla -r` |
